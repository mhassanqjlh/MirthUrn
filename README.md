# MirthUrn

MirthUrn enables high-performance, real-time data processing and routing through a message-bus-agnostic, fault-tolerant network processor.

With MirthUrn, you get a lightweight tool that stays out of your way.

**What you get**

- MirthUrn enables high-performance, real-time data
- processing and routing through a
- message-bus-agnostic, fault-tolerant network processor

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/MirthUrn.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
